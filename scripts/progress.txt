## Codebase Patterns
- `spring.config.import` in `application.properties` resolves paths relative to the process working directory (where `mvn` is run), NOT relative to `application.properties` itself.
- When running `mvn spring-boot:run` from `backend-java/portfolio/`, use `optional:file:.env[.properties]` (not `../.env`) to reference a `.env` file in that same directory.
- The `[.properties]` extension hint tells Spring to parse `.env` as Java properties format (`KEY=VALUE`), compatible with standard `.env` syntax (no `export`, no shell quoting, no `$VAR` references).
