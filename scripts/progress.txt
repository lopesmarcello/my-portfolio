## Codebase Patterns
- Tailwind CSS v4 uses `@custom-variant dark (&:is(.dark *));` in globals.css — dark mode is class-based
- globals.css has both `:root` and `.dark` CSS variable token definitions for shadcn
- sonner Toaster goes in the CMS layout (app/admin/(cms)/layout.tsx) with `position="bottom-right" duration={4000}`
- Admin CMS layout is at frontend/app/admin/(cms)/layout.tsx — it's the shared shell with sidebar and mobile nav
- Admin root layout is at frontend/app/admin/layout.tsx — thin wrapper, good place for ThemeProvider
