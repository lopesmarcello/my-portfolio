## Codebase Patterns
- Flyway 10+ requires BOTH `flyway-core` AND `flyway-database-postgresql` in pom.xml
- Spring Boot BOM manages Flyway version — no explicit version needed in pom.xml
- Disable Flyway for H2 test profile via `spring.flyway.enabled=false` in `application-test.properties`
- PostEntity (no @Table annotation) maps to table `post_entity` via Spring's CamelCaseToUnderscoresNamingStrategy
- Hibernate 6 `GenerationType.IDENTITY` on BIGINT → use `BIGINT GENERATED BY DEFAULT AS IDENTITY` in SQL migrations
- `@ElementCollection` tables have no primary key — just the FK join column + embeddable fields
- `ALTER TABLE t ALTER COLUMN c TYPE TEXT` is idempotent on PostgreSQL (safe even if already TEXT)
